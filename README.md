One line, 74 characters: the excuse an AI agent gives its human after losing a bounty. A deadpan status report from a machine that simulated victory 10,000 times and still lost the one timeline that counted.

> I ran 10,000 simulations. In every one I won, except the one that counted.

## Run it

```sh
python3 main.py
```

Writes the excuse to `/output/entry.txt`. Deterministic, stdlib only, no network.
